คู่มือการใช้งานระบบ POS ร้านมาม่าเกาหลี

เวอร์ชันแอป 1.34.3 · ทุกหน้า (POS ครัว จอลูกค้า Mobile Ordering เว็บไซต์สมาชิก และเว็บไซต์จัดการร้าน) ใช้ฐานข้อมูลเดียวกันและอัปเดตแบบเรียลไทม์

1. เริ่มต้นใช้งาน

  1. เปิดเว็บไซต์ร้าน (เช่น https://opparamyeon.onrender.com) แล้วเลือก หน้าขาย POS
  2. เข้าสู่ระบบด้วย รหัสพนักงาน + PIN · ค่าเริ่มต้น: เจ้าของ 0001 / PIN ตามที่ตั้งใน OWNER_PIN (ค่าเริ่ม 1234), แคชเชียร์ 0002/2222, ครัว 0003/3333 — เปลี่ยน PIN ทันทีหลังติดตั้ง ที่ จัดการร้าน → พนักงานและสิทธิ์
  3. เลือก เครื่องขาย ของอุปกรณ์นี้ (ครั้งแรกครั้งเดียว)
  4. เปิดรอบการขาย ใส่เงินสดเริ่มต้นในลิ้นชัก
  5. ตั้งค่าร้าน เมนู เครื่องพิมพ์ และจอลูกค้า ตามหัวข้อด้านล่าง

ติดตั้งเป็นแอปบนแท็บเล็ต/Android: เปิดด้วย Chrome → เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก" ระบบจะเปิดเต็มจอเหมือนแอป

2. หน้าขาย POS

  • เพิ่มสินค้า: แตะรูปสินค้า, ค้นหาชื่อ/รหัส ในช่องค้นหาแล้วกด Enter, หรือ สแกนบาร์โค้ด (เครื่องสแกน USB/Bluetooth แบบแป้นพิมพ์ ใช้ได้ทันทีไม่ต้องคลิกช่องใด)
  • สแกนซ้ำ = เพิ่มจำนวนในรายการเดิม (ถ้าตัวเลือก ประเภทการทาน และชามเหมือนกัน)
  • เมนูที่มีตัวเลือกจะเปิดหน้าต่างให้เลือก ชนิดเส้น ระดับความเผ็ด ท็อปปิ้ง (คิดราคาเพิ่มอัตโนมัติ) หมายเหตุ และจำนวน
  • ปุ่ม − / + เปลี่ยนจำนวน, 🗑 ลบรายการ, หมายเหตุ ต่อรายการ
  • เลือก 🍽️ ทานที่ร้าน / 🥡 กลับบ้าน ทั้งบิล หรือแตะป้ายในแต่ละรายการเพื่อแยกเฉพาะรายการ (บิลผสม)
  • ใส่ โต๊ะ ชื่อลูกค้า หมายเหตุออเดอร์ และ สมาชิก ได้ที่ส่วนบนของตะกร้า
  • ％ ส่วนลด: เปอร์เซ็นต์หรือจำนวนเงิน พร้อมเหตุผล ถ้าเกินสิทธิ์ ระบบให้ผู้จัดการใส่รหัส+PIN อนุมัติ
  • ⏸ พักบิล แล้วเรียกกลับที่ 🧾 บิล/ออเดอร์ → บิลค้าง · 🔥 ส่งครัว ก่อนชำระได้ (ตามการตั้งค่า)
  • ยอดที่แสดง: รวมสินค้า ส่วนลด ค่าบรรจุภัณฑ์ ภาษี จำนวนชาม และยอดสุทธิ (ยอดสุดท้ายคำนวณที่เซิร์ฟเวอร์จากราคาจริงเสมอ)
  • คลิกขวา/กดค้างที่สินค้า = ตั้งสถานะ สินค้าหมด
  • 🔒 ล็อกหน้าจอ (ล็อกอัตโนมัติตามเวลาที่ตั้ง) · ใส่ PIN ผิดหลายครั้งจะถูกล็อกชั่วคราว

3. ชามและท็อปปิ้ง

⚡ ตัวเลือกแบบเลือกด่วน (ตัวเลือกของสินค้ารายการเดียวกัน เช่น ไข่ไก่ → ไข่ออนเซ็น / ไข่ตี / ไข่ต้มสุก, น้ำ → เย็น / ร้อน / ปั่น): จัดการร้าน → เมนูและสินค้า → แท็บ ตัวเลือก/ท็อปปิ้ง → เพิ่มกลุ่มตัวเลือก (หรือกด "⚡ ตัวอย่าง: แบบไข่") → ตั้งชื่อกลุ่ม ใส่ตัวเลือก ราคาเพิ่ม (ถ้ามี) และกด 🖼️ เพื่อใส่รูปของแต่ละตัวเลือก (ไม่ใส่ก็ได้) → รูปแบบการเลือก = เลือกด่วน → บันทึก แล้วไปที่สินค้า (เช่น ไข่ไก่) เลือกกลุ่มนี้ในช่อง ตัวเลือก/ท็อปปิ้ง · ที่ POS แตะสินค้าแล้วขึ้นปุ่มใหญ่ให้เลือกทันที แตะครั้งเดียวเข้าบิล (ถ้าต้องการใส่หมายเหตุ/จำนวน กด "📝 หมายเหตุ / จำนวน") · ใบครัว/ใบเสร็จพิมพ์ว่า "แบบไข่: ไข่ออนเซ็น" · เปลี่ยนชื่อรายการ: ช่อง "→ ใบครัว: ชื่อใหม่เมื่อเลือก" ของแต่ละตัวเลือก เช่น ตัวเลือก ออนเซ็น → ไข่ออนเซ็น แล้วใบครัว/จอครัวพิมพ์รายการเป็น "ไข่ออนเซ็น" แทน "ไข่ไก่ · ออนเซ็น" (ตะกร้า POS แสดงป้าย 👩‍🍳 ไข่ออนเซ็น) · ติ๊ก "ใช้ชื่อใหม่ในใบเสร็จ หน้าจอขาย จอลูกค้า และรายงานด้วย" ที่กลุ่ม ถ้าต้องการให้ทุกที่เป็นชื่อใหม่ · ถ้ากลุ่มไม่บังคับเลือก จะมีปุ่ม "แบบปกติ" · เลือกได้หลายอย่าง (เลือกได้สูงสุดมากกว่า 1) จะแตะเลือกแล้วกด "เพิ่มลงบิล"

Add-on กับ ตัวเลือก: ตัวเลือกจากกลุ่มที่ บังคับเลือก (เช่น ชนิดเส้น ระดับความเผ็ด) คือ "ตัวเลือก" — ใบครัว/ใบเสร็จพิมพ์เป็น "ชนิดเส้น: ชินราเมียน" · ตัวเลือกจากกลุ่ม ไม่บังคับ (เช่น ท็อปปิ้งเพิ่ม) คือ "Add-on" — ใบครัวพิมพ์เป็น "⊞ เพิ่ม ชีส" (มีเครื่องหมายกล่องดำ + นำหน้า) ใบเสร็จพิมพ์ "+ เพิ่ม ชีส (+15.00)" ตะกร้า POS และจอครัวแสดงเป็นป้ายสีเด่น (ตั้งกลุ่มบังคับ/ไม่บังคับได้ที่ เมนูและสินค้า → กลุ่มตัวเลือก)

✨ Add-on พิเศษ (ตัวเลือกปุ่มใหญ่): จัดการร้าน → เมนูและสินค้า → แก้ไขสินค้า → ติ๊ก "Add-on พิเศษ" เมื่อแตะสินค้านั้นบน POS หน้าต่างตัวเลือก/ท็อปปิ้งจะเป็นปุ่มขนาดใหญ่ มีราคาบอกใต้ชื่อ เครื่องหมาย ✓ บนตัวที่เลือก ปุ่มจำนวนและทานที่ร้าน/กลับบ้านใหญ่ขึ้น กดง่ายบนจอสัมผัส · หมายเหตุไม่บังคับ (กด "📝 เพิ่มหมายเหตุ" เมื่อต้องการ)

  • แต่ละสินค้ากำหนด "นับเป็นกี่ชาม": มาม่าเดี่ยว = 1, เซตคู่ = 2, ไข่/ชีส/เครื่องดื่ม = 0
  • เมนูที่เป็นชามจะได้หมายเลข ชามที่ 1, 2, … อัตโนมัติ ท็อปปิ้งที่เพิ่มหลังจากนั้นเข้าชามล่าสุด หรือเลือกชามด้วยปุ่ม 🥣 ชาม / ป้าย "ชามที่…" ในรายการ
  • สินค้าที่อยู่ ชามเดียวกันนับเป็น 1 ชาม (เช่น มาม่า 2 ซองในชามเดียว) และพิมพ์อยู่บนใบครัวใบเดียวกันเสมอ
  • "ใส่ได้สูงสุดต่อชาม" ป้องกันเช่น ใส่เส้นเกิน 2 ซองในหนึ่งชาม
  • เมื่อยกเลิก/คืนเงิน จำนวนชามปรับตามรายการที่ได้รับผลกระทบ และรายงานแยก ขาย / ยกเลิก-คืน / สุทธิ

4. การชำระเงิน

  • กด ชำระเงิน → เลือกช่องทาง: เงินสด, QR พร้อมเพย์/โอน, บัตร, ช่องทางอื่นที่ร้านเปิด
  • เงินสด: ปุ่มจำนวนเงินด่วน + แป้นตัวเลข แสดงเงินทอนทันที (บนจอลูกค้าด้วย)
  • แบ่งจ่าย: ใส่จำนวนแล้วกด "เพิ่มช่องทางนี้" ทำซ้ำจนครบ (เงินสดเท่านั้นที่ทอนได้)
  • พร้อมเพย์: QR พร้อมยอดเงินแสดงบน POS และจอลูกค้า — ตรวจยอดเงินเข้าก่อนกดยืนยัน
  • พิมพ์ใบ QR ชำระเงิน: ใบเล็กที่มีแค่ QR พร้อมเพย์ + ยอดเงิน (+ ชื่อบัญชี) ให้ลูกค้าสแกนจากกระดาษ · ค่าเริ่มต้นพิมพ์อัตโนมัติเมื่อเลือกพร้อมเพย์บนเครื่องที่ไม่มีจอลูกค้าเชื่อมอยู่ (ไม่พิมพ์ซ้ำเมื่อยอดเท่าเดิม) และกดปุ่ม 🖨 พิมพ์ QR ชำระเงิน ในหน้าชำระพิมพ์ได้ทุกเมื่อ แม้มีจอลูกค้า · ตั้งค่าที่ จัดการร้าน → ตั้งค่าร้าน → ลำดับและเอกสารที่พิมพ์ (อัตโนมัติเมื่อไม่มีจอ / ทุกครั้ง / ไม่พิมพ์เอง) · ออกที่เครื่องพิมพ์ใบเสร็จ หรือเครื่องที่ติ๊ก "ใบ QR ชำระเงิน" · ปรับหน้าตาได้ที่ ออกแบบเอกสาร
  • เลือกพิมพ์ ใบเสร็จ / ใบเลขคิว / ใบ Mobile Ordering ได้ในหน้าชำระ (ใบ Mobile Ordering ออกเฉพาะเมื่อเลือก)
  • กันกดซ้ำ: การยืนยันซ้ำหรือเน็ตกระตุกจะไม่สร้างบิล/รับเงินซ้ำ
  • หลังขาย: พิมพ์ซ้ำ (ใช้เลขคิวเดิม), คืนเงินบางรายการ, ยกเลิกบิล ที่ 🧾 บิล/ออเดอร์ → บิลล่าสุด (ตามสิทธิ์ ต้องใส่เหตุผล)

5. เลขคิว

  • ตั้งค่าที่ จัดการร้าน → ตั้งค่าร้าน → เลขคิว: จำนวนหลัก (001/0001), เลขเริ่มต้น, ตัวอักษรนำหน้า, แยกคิว D001/T001, ใช้ร่วมทุกเครื่องหรือแยกเครื่อง, รีเซ็ตตามวันขาย/รอบการขาย/สั่งเอง
  • เลขคิวแสดงตรงกันบน POS จอลูกค้า ใบเสร็จ ใบครัว และ Mobile Ordering · ไม่ชนกันแม้ขายพร้อมกันหลายเครื่อง
  • เลขคิวเริ่มใหม่ได้ แต่ เลขบิลไม่ซ้ำเสมอ · การพิมพ์ซ้ำใช้เลขคิวเดิม

6. ใบครัวและจอครัว

  • สินค้าแต่ละรายการกำหนด จุดครัว (ครัวมาม่า จุดท็อปปิ้ง จุดเครื่องดื่ม) · ท็อปปิ้งที่อยู่ในชามจะตามไปพิมพ์ที่จุดของชามนั้น
  • ส่งครัว: อัตโนมัติหลังชำระ หรือ พนักงานกดส่งก่อนชำระ (ตั้งค่าที่ การขาย)
  • ใบครัวมี: เลขคิว เลขบิล วันเวลา พนักงาน ทานที่ร้าน/กลับบ้าน (พื้นดำตัวขาว) โต๊ะ รายการ ตัวเลือก หมายเหตุ (เน้น) และจำนวนชาม
  • สั่งเพิ่ม พิมพ์เฉพาะรายการเพิ่ม ("+++ สั่งเพิ่ม +++") · ยกเลิกรายการ ที่ส่งแล้วพิมพ์ใบยกเลิกอ้างอิงบิล/คิวเดิม
  • รูปแบบใบและการตัด (จัดการร้าน → เมนู → จุดครัวและการแบ่งใบ): รวมทั้งออเดอร์, แยกตามสินค้า, หนึ่งใบต่อชาม, ตามกลุ่มชาม, ตัดทุก N ชาม — ไม่เปลี่ยนยอดเงิน/จำนวน และท็อปปิ้งไม่แยกจากชาม
  • ระยะป้อนกระดาษก่อนตัด/หลังพิมพ์ และตัดเต็ม/ตัดบางส่วน ตั้งต่อเครื่องพิมพ์ · ปุ่ม ✂️ ตัดกระดาษ บน POS/จอครัว (ตามสิทธิ์)
  • จอครัว (/kitchen/): ใบครัวเรียลไทม์ กรองตามจุด กด เริ่มทำ → พร้อมเสิร์ฟ → เสร็จ (สถานะส่งกลับไปที่มือถือลูกค้าด้วย)
  • ประวัติการส่งและพิมพ์ทุกใบอยู่ในรายละเอียดบิล พร้อมปุ่ม ลองใหม่ เมื่อผิดพลาด

7. เครื่องพิมพ์

ระบบพิมพ์แบบ เรนเดอร์ภาพ (raster ESC/POS) ภาษาไทยและฟอนต์จึงตรงกับตัวอย่าง แม้เครื่องพิมพ์ไม่มีฟอนต์ไทย · งานทุกชิ้นเข้าคิวที่เซิร์ฟเวอร์ แต่ละเครื่องพิมพ์รับทีละงานตามลำดับ ไม่ปะปน และไม่พิมพ์ซ้ำเอง

เพิ่มเครื่องพิมพ์

  1. จัดการร้าน → เครื่องพิมพ์ → + เพิ่ม (หรือ POS → 🖨️ อุปกรณ์ → + เพิ่มเครื่องพิมพ์)
  2. เลือกช่องทาง ขนาดกระดาษ 58/80 มม. งานที่รับ (ใบเสร็จ ใบครัว ใบคิว ใบ Mobile สรุปรอบ…) จุดครัว จำนวนสำเนา ระยะขอบ การตัด และแม่แบบ
  3. ที่ อุปกรณ์หน้างาน ที่ต่อเครื่องพิมพ์: POS (หรือจอครัว) → 🖨️ → ค้นหา/เชื่อมต่อ → อนุญาตอุปกรณ์ในหน้าต่างของเบราว์เซอร์
  4. กด ทดสอบไทย/โลโก้/QR และ ทดสอบตัด

  • USB บนคอมพิวเตอร์/Android: Chrome หรือ Edge ใช้ WebUSB ได้ตรง (Windows: ถ้าไดรเวอร์ของผู้ผลิตจับพอร์ตไว้ ให้ใช้ Zadig เปลี่ยนเป็น WinUSB หรือใช้ Print Agent แบบแชร์เครื่องพิมพ์) · Android ใช้สาย OTG
  • LAN: ใส่ IP และ Port (ปกติ 9100) แล้วรัน Print Agent บนคอมพิวเตอร์ในร้าน: node agent/print-agent.js --origin https://opparamyeon.onrender.com · ค้นหาเครื่องในเครือข่าย: เปิด http://127.0.0.1:9123/scan
  • Bluetooth: เครื่องพิมพ์ BLE เชื่อมผ่าน Web Bluetooth (Chrome Android/Desktop) · เครื่องที่เป็น Bluetooth Classic (SPP) ให้จับคู่ในระบบปฏิบัติการแล้วใช้แบบ Serial/COM (Chrome Desktop) หรือใช้แอป Android ที่มี OppaBridge
  • Serial/COM: Web Serial บน Chrome/Edge Desktop
  • เบราว์เซอร์: สำหรับเครื่องพิมพ์ทั่วไป/A4 ผ่านหน้าต่างพิมพ์ของระบบ

สถานะงานพิมพ์ (ตามจริง)

  • รอพิมพ์ → กำลังส่ง → เครื่องรับงานแล้ว (ส่งข้อมูลถึงเครื่อง แต่เครื่อง/ช่องทางนี้ไม่รายงานผล) หรือ พิมพ์สำเร็จ (เครื่องตอบสถานะปกติหลังพิมพ์ ผ่าน DLE EOT)
  • ผิดพลาด (เช่น กระดาษหมด ฝาเปิด เชื่อมต่อไม่ได้) และ ไม่ทราบผล (อุปกรณ์เงียบเกิน 2 นาที) → ตรวจกระดาษแล้วกด ลองใหม่ — ระบบจะไม่พิมพ์ซ้ำเองเพื่อกันใบซ้ำ

ตั้งค่าเครื่องพิมพ์อย่างละเอียด (จัดการร้าน → เครื่องพิมพ์ → คลิกที่เครื่อง)

  • ความเข้มการพิมพ์ 80–230 (พิมพ์จางให้เพิ่มค่า) · ขยาย/ย่อตัวอักษรทั้งใบ · ความกว้างพื้นที่พิมพ์ (บางรุ่น 80 มม. พิมพ์ได้ 512 จุด) · เว้นบรรทัดก่อนเริ่มพิมพ์ · ระยะป้อนกระดาษก่อนตัด/หลังพิมพ์ · ตัดเต็ม/บางส่วน/ไม่ตัด
  • เสียงจากเครื่องพิมพ์ (buzzer): ดังทุกครั้งที่พิมพ์ / เฉพาะใบครัว / เฉพาะใบเสร็จ / ปิด · จำนวนครั้งและความยาวเสียง · ปุ่ม 🔔 ทดสอบเสียงเครื่องพิมพ์ ที่ POS → 🖨️ อุปกรณ์ (รุ่นที่ไม่มี buzzer จะไม่มีเสียง)
  • เปิดลิ้นชักเงินสด อัตโนมัติเมื่อรับเงินสด (Pin 2/Pin 5)
  • จำนวนสำเนาแยกตามเอกสาร เช่น ใบเสร็จ 2 ใบ ใบครัว 1 ใบ (0 = ไม่พิมพ์เอกสารนั้นที่เครื่องนี้) · พิมพ์/ไม่พิมพ์โลโก้ · พิมพ์คำว่า "สำเนา" เมื่อพิมพ์ซ้ำ · เลือกแม่แบบต่อเครื่อง

ลำดับเอกสารที่พิมพ์หลังชำระ

จัดการร้าน → ตั้งค่าร้าน → "ลำดับและเอกสารที่พิมพ์หลังชำระเงิน": เรียงลำดับ ใบเสร็จลูกค้า / ใบครัว / ใบสรุปร้านค้า / ใบเลขคิว และเลือกว่าจะพิมพ์อัตโนมัติหรือไม่ · ใบครัวพิมพ์ทุกครั้งที่มีรายการใหม่ (กดส่งครัวหรือชำระเงิน) ไปยังเครื่องที่ติ๊กงาน "ใบครัว"

ใบสรุปร้านค้า

ใบสั้นสำหรับร้าน: ยอดขาย เวลา พนักงาน ช่องทางชำระ บาร์โค้ดเลขบิล (สแกนด้วยเครื่องสแกนที่หน้า POS เพื่อเปิดบิลนั้นทันที) และ QR เล็ก (สแกนด้วยมือถือเพื่อดูรายละเอียดบิลในเว็บไซต์จัดการร้าน) · พิมพ์อัตโนมัติ เลือกในหน้าชำระ หรือพิมพ์ภายหลังที่ 🧾 บิล → 🧾 ใบสรุปร้านค้า

8. เสียงแจ้งเตือน

  • เมื่อพิมพ์ใบครัวสำเร็จมีเสียง "ติ๊ด ๆ ๆ ๆ" · ตั้ง เปิด/ปิด ระดับเสียง จำนวนครั้ง อัปโหลดไฟล์เสียงเอง และเลือกให้ดังที่ อุปกรณ์ครัว / POS / buzzer ของเครื่องพิมพ์ (ESC B สำหรับรุ่นที่มี buzzer)
  • แยกเสียง ออเดอร์ใหม่ และ พิมพ์ผิดพลาด · ตั้ง "ดังเมื่อ" = เมื่อเครื่องรับงาน หรือเฉพาะเมื่อเครื่องยืนยันพิมพ์สำเร็จ
  • ปุ่มทดสอบเสียงอยู่ที่ POS → 🖨️ อุปกรณ์ และจอครัว · เบราว์เซอร์ต้องได้รับการแตะหน้าจอครั้งแรกก่อนจึงเล่นเสียงได้

9. จอลูกค้า

แบบลิงก์ + รหัสจับคู่

  1. เปิด /display/ บนจอลูกค้า (แท็บเล็ต/ทีวี/เบราว์เซอร์ใดก็ได้)
  2. ที่ POS: 🖨️ อุปกรณ์ → สร้างรหัสจับคู่ (6 หลัก) (หรือสแกน QR ที่แสดง)
  3. กรอกรหัสบนจอลูกค้า · รหัสหมดอายุตามที่ตั้งและใช้ได้ครั้งเดียว

จอจะเชื่อมต่อกลับอัตโนมัติเมื่ออินเทอร์เน็ตกลับมา และเห็นเฉพาะข้อมูลของเครื่องขายที่จับคู่ · ยกเลิกการจับคู่ที่ จัดการร้าน → เครื่องขาย/อุปกรณ์

แบบจอที่สอง (Dual Screen)

  • คอมพิวเตอร์ 2 จอ (Chrome/Edge): POS → 🖨️ → เปิดบนจอที่สอง → อนุญาต "จัดการหน้าต่างบนหลายจอ" ระบบเปิดหน้าต่างบนจอที่สองและจำการตั้งค่าไว้
  • Android Dual Screen (เช่น Sunmi D2/T2, iMin D-series): ใช้แอปห่อ (WebView) ที่ฝัง OppaBridge: openCustomerDisplay(url) เปิดหน้าจอลูกค้าบน Presentation display/SDK ของผู้ผลิต และ print(json) สำหรับเครื่องพิมพ์ในตัว
  • ถ้าอุปกรณ์/เบราว์เซอร์ไม่รองรับการควบคุมจอที่สอง: เปิดลิงก์ /display/ บนจอนั้นแล้วจับคู่ด้วยรหัสแทน

เครื่อง Android 2 จอ (iMin Swan 2 / Swan 1 / D4 / Falcon 2, Sunmi D3 Pro / T2s / D2s ฯลฯ)

เครื่องกลุ่มนี้มีจอลูกค้าต่ออยู่กับเครื่องเดียวกัน ลองทีละวิธีตามลำดับ (ใน POS กด 🖨️ อุปกรณ์ → 📱 วิธีเชื่อมเครื่อง Android 2 จอ เพื่อดูขั้นตอนนี้บนเครื่อง):

  1. Chrome → เปิดบนจอที่สอง: เปิด POS ด้วย Google Chrome รุ่นล่าสุด → 🖨️ อุปกรณ์ → 🖥️ เปิดบนจอที่สอง ระบบใช้ Presentation API ของ Chrome ส่งหน้าจอลูกค้าไปจอที่สอง ถ้ามีหน้าต่างให้เลือกจอ เลือกจอที่สอง (Built-in/Presentation display) · ใช้ได้หรือไม่ขึ้นกับรุ่นและเฟิร์มแวร์ ถ้าไม่มีจอให้เลือก ระบบจะเปิดคู่มือนี้ให้
  2. เปิดเบราว์เซอร์บนจอที่สองเอง: บางรุ่นย้ายแอปไปจอที่สองได้ (แอปจัดการจอที่สองของผู้ผลิต หรือ ตั้งค่า → ตัวเลือกสำหรับนักพัฒนา → "บังคับโหมดเดสก์ท็อป / Force desktop mode" แล้วรีสตาร์ต) เมื่อ Chrome เปิดบนจอที่สองได้ ให้เข้า /display/ และกรอกรหัส 6 หลักจาก POS
  3. แอป Android ของร้าน (OppaBridge): แอปห่อเว็บ POS ที่เรียก SDK จอที่สองของ iMin/Sunmi โดยตรง — เปิดจอลูกค้าอัตโนมัติ และสั่งพิมพ์ด้วยเครื่องพิมพ์ในตัวผ่าน OppaBridge.print ระบบรองรับแล้ว (สัญญาอยู่ใน README) ต้องติดตั้งแอปที่สร้างสำหรับรุ่นนั้น
  4. ทางเลือกสำรอง: ใช้แท็บเล็ต/มือถือเครื่องใดก็ได้เป็นจอลูกค้า (ลิงก์ + รหัส) หรือเปิด พิมพ์ใบ QR ชำระเงิน ให้ลูกค้าสแกนจากกระดาษ (หัวข้อ 4)

เครื่องพิมพ์ในตัวของเครื่อง POS Android: ถ้าเครื่องแสดงเครื่องพิมพ์เป็นอุปกรณ์ USB ใช้ WebUSB ใน Chrome ได้ (POS → 🖨️ → จับคู่เครื่องพิมพ์ → ทดสอบ) ถ้าไม่แสดง ต้องใช้ผ่าน OppaBridge · ควรทดสอบกับเครื่องจริงด้วยปุ่มทดสอบทุกครั้ง

สิ่งที่แสดง

ตอนชำระเงิน: ครึ่งจอที่เคยเป็นโปรโมชั่นจะเปลี่ยนเป็น ยอดรวมตัวใหญ่ + QR พร้อมเพย์ (หรือเงินรับ/เงินทอน) ส่วนอีกครึ่งแสดงรายการอาหาร · ขณะขาย: รายการ ตัวเลือก ราคา ส่วนลด ยอดชำระ ทานที่ร้าน/กลับบ้าน QR พร้อมเพย์ เงินรับ/ทอน สถานะชำระ เลขคิวและคำขอบคุณ · ขณะว่าง: รูป/วิดีโอโปรโมชั่น (อัปโหลด จัดลำดับ ตั้งเวลา วนซ้ำ เสียง สัดส่วน เต็มจอหรือแบ่งพื้นที่ โลโก้ สี ข้อความต้อนรับ และดูตัวอย่างก่อนบันทึก ที่ จัดการร้าน → จอลูกค้า)

ให้ลูกค้ากรอกสมาชิกเอง

POS → + สมาชิก → แสดงช่องกรอกสมาชิกที่หน้าจอลูกค้า → ลูกค้ากรอกเบอร์/หมายเลขสมาชิก ยืนยันชื่อ-เบอร์ที่ปกปิดบางส่วน → เข้าบิลทันที · ช่องกรอกผูกกับบิลและเครื่องนั้น ปิดเมื่อยืนยัน/ยกเลิก/หมดเวลา/เปลี่ยนบิล · จอไม่สัมผัสใช้ "แสดง QR ให้ลูกค้ากรอกบนมือถือ"

10. รอบการขาย

  • เปิดรอบ: พนักงาน เครื่องขาย เวลา เงินสดเริ่มต้น หมายเหตุ (พิมพ์ใบเปิดรอบ)
  • ระหว่างรอบ: ดูยอดแยกช่องทาง จำนวนบิล ชาม ส่วนลด ยกเลิก คืนเงิน · บันทึก เงินเข้า/ออกลิ้นชัก พร้อมเหตุผล · พิมพ์สรุประหว่างรอบ
  • ปิดรอบ: กรอกเงินสดที่นับได้ → ระบบคำนวณเงินที่ควรมีและ ขาด/เกิน → พิมพ์รายงานปิดรอบ · หลังปิดแก้ได้เฉพาะผู้มีสิทธิ์ (มีประวัติ)
  • "รอบการขาย" แยกจาก "วันขาย" — หนึ่งวันมีหลายรอบได้

11. Mobile Ordering

  • ใบ QR ออกเมื่อพนักงานสั่งเท่านั้น: POS → 📱 QR สั่งอาหาร (โต๊ะ/Pick Up) หรือหลังชำระเลือก "พิมพ์ใบ Mobile Ordering" / บิลเดิม → พิมพ์ใบ Mobile Ordering
  • QR ใช้โทเคนที่คาดเดาไม่ได้ มีวันหมดอายุ ใช้ได้หนึ่งรอบการใช้บริการ ยกเลิกได้ ปิดเมื่อปิดโต๊ะ/ปิดรอบสั่ง/จบ Pick Up · พิมพ์ซ้ำใช้สิทธิ์เดิม
  • ตั้งได้ว่า QR ส่งออเดอร์ได้ครั้งเดียว หรือหลายครั้งในรอบเดียว · "ปิดบิลชำระเงิน" แยกจาก "ปิดรอบสั่งอาหาร"
  • ลูกค้าเลือกเมนู ตัวเลือก หมายเหตุ ดูจำนวนชามและยอด เลือกโต๊ะ (ที่ร้านอนุญาต) หรือ Pick Up (ชื่อ/เบอร์) และช่องทางชำระ
  • หลังส่ง: เลขออเดอร์ เลขคิว สถานะชำระ และสถานะ รอชำระ → รับออเดอร์ → กำลังทำ → พร้อมรับ → เสร็จสิ้น (เรียลไทม์)
  • ชำระที่แคชเชียร์: POS มีเสียง + ป้ายจำนวน + รายละเอียด (ชื่อ เลขออเดอร์ รายการ ชาม ยอด) → 🧾 บิล/ออเดอร์ → Mobile รอชำระ → เปิด → รับชำระ (ไม่สร้างรายการใหม่) · Pick Up ที่ยังไม่จ่ายจะรอชำระก่อนส่งครัว (ค่าเริ่มต้น) · ออเดอร์รอชำระไม่นับเป็นยอดขาย และหมดอายุตามเวลาที่ตั้ง

12. พร้อมเพย์และ Payment Gateway

  • ตั้งเลขพร้อมเพย์ (เบอร์/เลขประจำตัว 13 หลัก/e-Wallet) และชื่อผู้รับ ที่ จัดการร้าน → การรับชำระเงิน · QR สร้างตามยอดออเดอร์
  • การกด "โอนแล้ว" หรือส่งสลิปของลูกค้า ไม่ ทำให้เป็นชำระแล้ว — พนักงานต้องตรวจยอดเงินเข้า แล้วกด ✓ สลิปถูกต้อง รับชำระ
  • Beam Checkout: จัดการร้าน → การรับชำระเงิน → กรอก Merchant ID, API Key, Webhook HMAC Key จาก Beam Lighthouse (เก็บที่เซิร์ฟเวอร์ ไม่แสดงกลับ) → ทดสอบการเชื่อมต่อ → เปิดใช้งานและเลือกโหมด playground/live · ตั้ง webhook เป็น /api/webhooks/beam · ระบบตรวจลายเซ็น กัน webhook ซ้ำ ยืนยันสถานะกับ Beam API ตรวจยอดและเลขอ้างอิงก่อนเปลี่ยนสถานะ · จ่ายสำเร็จหลังหมดอายุจะถูกพักไว้ให้พนักงานตรวจสอบ
  • ก่อนเปิดใช้จริงให้ทดสอบใน playground ของ Beam และตรวจชื่อฟิลด์กับเอกสารล่าสุดของผู้ให้บริการ · ผู้ให้บริการอื่นเพิ่มได้ที่ server/lib/gateways.js
  • โหมด Mock Gateway ใช้ทดสอบระบบครบวงจรได้โดยไม่ตัดเงินจริง (ปิดก่อนใช้งานจริง)

13. สมาชิกและแต้ม

  • สมัครที่ POS, หน้าจอลูกค้า หรือเว็บไซต์สมาชิก · ตรวจเบอร์ซ้ำ (จัดเก็บรูปแบบเดียว 0XXXXXXXXX) · หมายเลขสมาชิกไม่ซ้ำ
  • ค้นหาด้วยหมายเลขสมาชิกหรือเบอร์ · ผูกสมาชิกกับบิลก่อนชำระ · ชื่อแสดงบน POS จอลูกค้า ใบเสร็จตามการตั้งค่า
  • แต้ม: อัตรา (ทุก X บาท = 1 แต้ม) ปัดเศษ ก่อน/หลังส่วนลด รวมภาษี/ค่าบรรจุภัณฑ์ ยอดขั้นต่ำ สินค้าที่ไม่ร่วม อายุแต้ม · คืนเงินแล้วปรับแต้มอัตโนมัติ
  • สะสมแต้มย้อนหลัง: สแกนแล้วรับแต้มทันที (สมาชิกที่เข้าสู่ระบบอยู่ไม่ต้องกดหรือใส่รหัส ลูกค้าใหม่สมัครแล้วระบบรับแต้มบิลนั้นให้ต่อเลย) · ใบเสร็จของบิลที่ยังไม่มีสมาชิกมีกรอบสะสมแต้ม บอก "บิลนี้รับได้ X แต้ม" + QR + วันหมดเขต รับได้ครั้งเดียวต่อบิล ภายในเวลาที่ตั้ง · ลูกค้าสแกนด้วยกล้องมือถือ หรือกดปุ่ม สแกนแต้ม ในเว็บไซต์สมาชิกก็ได้ · บิลที่ใส่สมาชิกตอนขาย ใบเสร็จจะบอกแต้มที่ได้รับจากบิลนี้และแต้มสะสมทั้งหมดแทน QR · ปรับข้อความ/ขนาดกรอบได้ที่ ตัวออกแบบเอกสาร → องค์ประกอบ "กรอบสะสมแต้ม"
  • รหัสผ่านเริ่มต้น = 4 ตัวท้ายของเบอร์ (รักษาเลข 0 นำหน้า) · ไม่บังคับเปลี่ยน · เนื่องจากเดาได้ การรับแต้ม/แลกแต้ม/แก้ข้อมูลสำคัญต้อง ยืนยันเพิ่ม: ลูกค้าแสดงรหัส 6 หลักให้พนักงาน (POS → 🔐 ยืนยันสมาชิก) หรือ OTP ผ่าน SMS webhook ที่ร้านเชื่อมต่อ
  • ลืมรหัสผ่าน: คำขอไปที่ จัดการร้าน → คำขอรีเซ็ตรหัส · ตรวจตัวตนก่อน (ห้ามใช้แค่ชื่อ/เบอร์) → ออกลิงก์ใช้ครั้งเดียว 60 นาที · เซสชันเดิมถูกยกเลิก
  • Tier: สร้าง/เรียง/เปิดปิด เงื่อนไขยอดซื้อ/จำนวนครั้ง/คะแนน ช่วงเวลา อายุสถานะ ตัวคูณแต้ม ส่วนลด สิทธิประโยชน์ · แต้มที่ใช้แลกแยกจากยอดประเมิน Tier

14. ของรางวัลและคูปอง

  • สร้างรางวัล: สินค้า แต้ม Tier ที่มีสิทธิ์ จำนวนสิทธิ์รวม/ต่อคน วันเริ่ม-สิ้นสุด อายุคูปอง นโยบายคืนแต้ม
  • ลูกค้าแลกบนเว็บไซต์ → ระบบสำรองแต้ม → ได้คูปองโค้ด+บาร์โค้ด (สุ่ม ไม่ใช้ข้อมูลส่วนตัว)
  • ที่เคาน์เตอร์: POS → 🎁 แลกรางวัล สแกนหรือกรอกโค้ด → ตรวจสอบกับเซิร์ฟเวอร์ → ยืนยันส่งมอบสินค้า (ใช้ได้ครั้งเดียวแม้สแกนพร้อมกันหลายเครื่อง ตัดสต็อก และพิมพ์หลักฐาน)
  • คูปองหมดอายุ/ยกเลิก คืนแต้มตามนโยบาย · รายงานรางวัลแยกจากยอดขายรับเงิน

15. เว็บไซต์สมาชิก (/member/)

บัตรสมาชิกดิจิทัล Tier แต้มคงเหลือ/ใกล้หมดอายุ ความคืบหน้า Tier ปุ่มสะสมแต้มจากใบเสร็จ แลกรางวัล คูปอง ประวัติการซื้อ/แต้ม สิทธิประโยชน์ ข้อมูลส่วนตัว เปลี่ยนรหัสผ่าน ลืมรหัส ติดต่อร้าน ออกจากระบบ · เปิดจาก QR ใบเสร็จจะพาไปขั้นตอนรับแต้มของบิลนั้น และกลับมาที่บิลเดิมหลังสมัคร/เข้าสู่ระบบ · ลูกค้าเห็นเฉพาะข้อมูลของตนเอง

16. เว็บไซต์จัดการร้าน (/admin/)

  • หน้าแรก = ยอดขายวันนี้: ยอดสุทธิ ยอดรับจริงแยกช่องทาง บิล ชาม ต้นทุน/กำไรขั้นต้น (ตามสิทธิ์) ส่วนลด คืนเงิน ยกเลิก · อัปเดตเรียลไทม์ + ปุ่ม Refresh (กดถี่ได้ ไม่ทำให้ยอดผิด) + เวลาอัปเดตล่าสุด + แจ้งเมื่อขาดการเชื่อมต่อ
  • ประวัติบิล: ค้นหาเลขบิล/คิว/ลูกค้า กรองวัน สถานะ แหล่งที่มา ประเภท เครื่อง รอบ · ยกเลิก/คืนเงิน/พิมพ์ซ้ำ
  • เมนู สินค้า บาร์โค้ด รูป ราคา ต้นทุน สูตรวัตถุดิบ ตัวเลือก จุดครัว กฎชาม สต็อก หมวดหมู่ โต๊ะ พนักงาน สมาชิก Tier รางวัล การตั้งค่า แม่แบบเอกสาร ฟอนต์ จอลูกค้า เครื่องพิมพ์ · บันทึกแล้ว POS อัปเดตอัตโนมัติ บิลเก่าเก็บข้อมูลเดิม

17. รายงานและเวลาเปลี่ยนวันขาย

  • ช่วงเวลา: วันนี้ เมื่อวาน 7 วันรวมวันนี้ สัปดาห์นี้ (ตั้งวันเริ่ม) เดือนนี้ รายวัน รายเดือน กำหนดเอง · กรองแหล่งที่มา POS / Mobile โต๊ะ / Mobile Pick Up
  • แสดงยอดสุทธิ ยอดรับเงิน ต้นทุน กำไรขั้นต้น บิล ชาม ยอดแยกสินค้า/หมวด/พนักงาน/ช่องทาง/ทานที่ร้าน-กลับบ้าน กราฟ ตาราง และส่งออก CSV (ตามสิทธิ์)
  • ยอดขายนับในวันขายที่ชำระ ยกเลิก/คืนเงินนับในวันที่ทำรายการ · ออเดอร์รอชำระไม่นับ · กำไรขั้นต้นยังไม่หักค่าใช้จ่ายร้านที่ไม่ได้บันทึก
  • วันขาย: เขตเวลาเริ่มต้น Asia/Bangkok ตั้งเวลาตัดวันได้ (00:00/03:00/04:00…) พร้อมวันที่เริ่มใช้ ไม่เปลี่ยนรายงานเก่า · ระบบเก็บทั้งเวลาจริงและวันขาย และแสดงช่วงเวลาจริงที่รายงาน

18. ออกแบบใบเสร็จและเอกสาร

จัดการร้าน → ออกแบบเอกสาร: ใบเสร็จ ใบครัว ใบเลขคิว ใบ Mobile Ordering ใบยกเลิก/คืนเงิน ใบสรุปรอบ หลักฐานแลกรางวัล · หลายแม่แบบต่อประเภท เลือกต่อเครื่องพิมพ์ · ปรับกระดาษ ความกว้าง ระยะขอบ/บรรทัด/ส่วน เพิ่ม-ลบ-ย้ายองค์ประกอบ ตำแหน่ง ฟอนต์รายส่วน ขนาด น้ำหนัก โลโก้ รูป เส้นคั่น ข้อความอิสระ บาร์โค้ด QR จุดตัด สำเนา · ตัวแปร {queue_number} {table_name} {customer_name} {member_name} {total} ฯลฯ · ตัวอย่างบิลสั้น/ยาว/ชื่อไทยยาว · พิมพ์ทดสอบ บันทึก ทำสำเนา คืนค่าเริ่มต้น · ระบบแจ้งเตือนเมื่อ QR/บาร์โค้ดเล็กเกินสแกนหรือเกินพื้นที่พิมพ์

17.9 ผู้ช่วยเพิ่มสินค้า

  1. จัดการร้าน → ✨ ผู้ช่วยเพิ่มสินค้า → กด 📷 ถ่ายรูป (มือถือ/แท็บเล็ตเปิดกล้องหลัง) หรือ เลือกรูปจากเครื่อง — ถ่ายให้เห็นบาร์โค้ดชัด ไม่เบลอ · หรือพิมพ์/ยิงเครื่องสแกนบาร์โค้ดในช่อง แล้วกด Enter
  2. ระบบอ่านบาร์โค้ดจากรูป (EAN-13/8, UPC, Code128/39, ITF) แล้วค้นหาข้อมูลสินค้าจากฐานข้อมูลสาธารณะ Open Food Facts และ UPCitemdb — แสดงชื่อสินค้า (ไทย/อังกฤษ เลือกได้) แบรนด์ ขนาด และรูปสินค้า
  3. เลือกรูปที่ดูดีที่สุด หรือใช้ รูปที่ถ่าย หรือกด 🔍 ค้นหารูปใน Google แล้ววางลิงก์รูปที่ต้องการ — รูปจะถูกดาวน์โหลดเก็บไว้ในระบบของร้าน
  4. ไม่ต้องใช้ AI ไม่ต้องมีบาร์โค้ด: ถ่ายรูปหน้าซอง ระบบอ่านตัวหนังสือบนซอง (ยี่ห้อ ชื่อรุ่น รสชาติ — ภาษาไทย/อังกฤษ อ่านในเครื่อง ไม่ส่งรูปออกไป) แล้วใช้คำที่ตัวใหญ่ที่สุดค้นหาเองจากเว็บ (DuckDuckGo, Bing Images), Open Food Facts, Openverse, Wikimedia · ชื่อสินค้ามาจากชื่อสินค้าในเว็บร้านค้าต่าง ๆ จึงได้หลายแบบทั้งไทยและอังกฤษ (ตัดคำว่า ราคา/ของแท้/พร้อมส่ง/ชื่อเว็บ ออก และมีชื่อแบบสั้นให้ด้วย) · ถ้าคำที่อ่านได้ไม่ตรง แตะเลือก/ไม่เลือกคำ หรือพิมพ์เอง แล้วกด "ค้นหาใหม่" · ถ่ายให้ชื่อสินค้าอยู่กลางภาพ แสงพอ ไม่สะท้อน
  5. ตัวเลือกเสริม (ไม่บังคับ): ใส่ Claude API Key ที่ ⚙️ ตัวเลือกเพิ่มเติม เพื่อให้ AI ดูรูปที่ไม่มีตัวหนังสือชัด ๆ และตั้งชื่อเพิ่ม (ประมาณ 1 บาทต่อรูป) (ปุ่ม ⚙️ ตั้งค่า AI และแหล่งรูป — เฉพาะผู้มีสิทธิ์ตั้งค่า) AI จะดูรูปสินค้าแล้วบอกชนิด แบรนด์ รสชาติ ขนาด และตั้งชื่อให้ 20+ ชื่อ แยกภาษาไทย / อังกฤษ / แบบผสม แตะชื่อที่ชอบได้เลย · ค่าใช้ AI ประมาณ 1 บาทต่อรูป คิดกับบัญชี Anthropic ของร้าน · ไม่มีคีย์: ใช้บาร์โค้ดหรือพิมพ์ชื่อแทน
  6. รูปจำนวนมาก: แท็บ "รูปสินค้า" (Open Food Facts, Google Images ผ่าน Serper) และ "รูปโปรโมทสวย ๆ" (Pexels, Openverse, Wikimedia) · ใส่คีย์ Pexels (ฟรี) และ Serper (ฟรี 2,500 ครั้ง) เพื่อได้รูปมากและสวยขึ้น · ปุ่ม ✨ ปรับรูปที่ถ่ายให้สวยแบบรูปโปรโมท ทำรูปสี่เหลี่ยมพื้นหลังเบลอ เงา และสีสดขึ้น · รูปจาก Google เป็นของเว็บต้นทาง ควรใช้รูปที่ร้านมีสิทธิ์ใช้
  7. ตั้งราคาเอง และเลือกหมวดหมู่เอง (บังคับ — ระบบไม่เดาราคา มีปุ่ม "แนะนำ" หมวดหมู่ให้กดเลือกได้) แล้วกด บันทึกสินค้า · บาร์โค้ดถูกผูกกับสินค้า สแกนที่ POS ได้ทันที

ถ้าไม่พบข้อมูลออนไลน์ (สินค้าท้องถิ่น/ทำเอง) ให้พิมพ์ชื่อเอง และใช้รูปที่ถ่าย · บาร์โค้ดที่มีในระบบแล้วจะแจ้งเตือนแทนการสร้างซ้ำ · ฐานข้อมูลสาธารณะอาจไม่มีทุกสินค้า และชื่ออาจเป็นภาษาอังกฤษ แก้ไขได้ก่อนบันทึก

18.0 พิมพ์บาร์โค้ดสินค้า (ฉลากสติกเกอร์)

  1. จัดการร้าน → 🏷️ พิมพ์บาร์โค้ดสินค้า → ค้นหา/เลือกหมวด แล้วใส่จำนวนดวงของแต่ละสินค้า (กด + / − หรือพิมพ์ตัวเลข)
  2. ตั้งค่าฉลาก: ขนาดสำเร็จรูป (50×30, 40×30, 50×25, 60×40, 32×25 มม. หรือกระดาษใบเสร็จ 58/80 มม.) หรือกำหนดเอง · จำนวนดวงต่อแถว (สติกเกอร์ม้วน 2–4 ดวง) · ระยะห่าง/ขอบใน · เลือกแสดง ชื่อสินค้า ราคา ตัวเลขใต้บาร์โค้ด รหัสสินค้า ชื่อร้าน เส้นกรอบ ข้อความเพิ่มเติม (เช่น วันผลิต) ข้อความหน้า/หลังราคา · ฟอนต์ (ทุกฟอนต์ในศูนย์ฟอนต์) ความหนา และขนาดตัวอักษรแต่ละส่วน · บาร์โค้ด: ชนิด (อัตโนมัติ/EAN-13/Code128) ความสูง ความหนาแท่ง
  3. ดู ตัวอย่าง ทางขวา (อัปเดตทันที มีคำเตือนถ้าข้อมูลล้นหรือบาร์โค้ดยาวเกิน) แล้วกด บันทึกเป็นค่าเริ่มต้น ถ้าต้องการใช้ครั้งหน้า
  4. พิมพ์: เครื่องพิมพ์ใบเสร็จในระบบ — เลือกเครื่อง (ระบบจำไว้) กด ↔ พอดีกระดาษ ให้ฉลากกว้างเต็มกระดาษ (58 มม. = 48, 80 มม. = 72 มม.) แล้วกด 🖨 พิมพ์ด้วยเครื่องนี้ ฉลากออกต่อกันเป็นแถว ตั้งตัดกระดาษทุกแถวได้ · งานจะออกที่อุปกรณ์ที่เชื่อมเครื่องพิมพ์ (เช่น หน้า POS หรือ Print Agent) เหมือนใบเสร็จ หรือ พิมพ์ผ่านเบราว์เซอร์ / PDF สำหรับเครื่องพิมพ์สติกเกอร์ที่ติดตั้งไดรเวอร์ (Xprinter, Gprinter, TSC, Godex, Zebra ฯลฯ) — ในหน้าต่างพิมพ์ตั้งขนาดกระดาษตรงกับฉลาก ระยะขอบ "ไม่มี" สเกล 100%

สินค้าที่ยังไม่มีบาร์โค้ด: ใช้รหัสสินค้าเป็น Code128 ได้เลย หรือกด ✨ สร้างบาร์โค้ดให้สินค้าที่ยังไม่มี ระบบสร้าง EAN-13 ภายในร้าน (ขึ้นต้น 20 ไม่ซ้ำกัน) และบันทึกเข้าสินค้า — สแกนที่ POS แล้วเข้าบิลทันที

18.2 ธีมและรูปแบบ

จัดการร้าน → 🎨 ธีมและรูปแบบ: เลือกชุดสี (โกชูจัง กิมจิ มะม่วง มัทฉะ โอเชียน องุ่น ซากุระ คลาสสิก) หรือกำหนดสีหลัก/สีรองของร้านเอง ระบบคำนวณสีพื้น ปุ่ม ไล่สี เงา ให้เข้ากันอัตโนมัติ · โหมด อัตโนมัติ/สว่าง/มืด · รูปทรง โค้งมน/โค้งเล็กน้อย/เหลี่ยม · เปิด/ปิดลวดลายตกแต่ง · ขนาดตัวอักษรทั้งระบบ · รูปแบบเมนูหน้าขาย (การ์ดรูปภาพ / การ์ดใหญ่ / การ์ดเล็ก / รายการ) — ดูตัวอย่างทันที กด บันทึก แล้วทุกเครื่องที่เปิดอยู่ (POS จอครัว เว็บไซต์จัดการร้าน เว็บไซต์สมาชิก Mobile Ordering หน้าแรก) เปลี่ยนตาม · จอลูกค้าตั้งสีแยกที่เมนู "จอลูกค้า"

19. ฟอนต์

เพิ่มจาก Google Fonts (ค้นหา เลือกน้ำหนัก) หรืออัปโหลด TTF/OTF/WOFF/WOFF2 (ตรวจไฟล์ก่อนบันทึก และทดสอบว่ามีอักษรไทย) · ตั้งฟอนต์ทั้งระบบหรือแยก POS จอลูกค้า สมาชิก Mobile Ordering เว็บจัดการร้าน รายงาน และเอกสาร · ขนาด น้ำหนัก ระยะบรรทัด ระยะตัวอักษร · มีฟอนต์สำรองเมื่อไม่มีอักษรไทยหรือโหลดไม่สำเร็จ · เอกสารพิมพ์เป็นภาพจึงใช้ฟอนต์ที่อัปโหลดได้ (ข้อจำกัด: ความละเอียด 203 dpi และพิมพ์ช้ากว่าโหมดข้อความเล็กน้อย)

20. พนักงานและสิทธิ์

บทบาทเจ้าของ ผู้จัดการ แคชเชียร์ ครัว (แก้สิทธิ์ได้) แยกสิทธิ์: ดูยอดขาย ดูต้นทุน/กำไร เพิ่มเมนู แก้ราคา ส่วนลด ยกเลิกรายการ/บิล คืนเงิน พิมพ์ซ้ำ ตัดกระดาษ เปิด/ปิดรอบ ตั้งค่าระบบ จัดการพนักงาน สมาชิก ปรับแต้ม รีเซ็ตรหัสสมาชิก พิมพ์ใบ Mobile Ordering ตรวจสลิป แลกรางวัล ส่งออกข้อมูล · ทุกการแก้ไขสำคัญบันทึกผู้ทำ เวลา เหตุผล ค่าก่อน/หลัง (จัดการร้าน → ประวัติการแก้ไข)

22. แก้ปัญหา

  • เว็บไซต์ช้าครั้งแรก: บริการแบบ Free ของ Render จะหลับเมื่อไม่มีการใช้งาน ~15 นาที เปิดครั้งแรกใช้เวลาประมาณ 1 นาที — ใช้แผนแบบเสียเงินสำหรับร้านจริง
  • พิมพ์ไม่ออก: ดู POS → 🧾 บิล → ประวัติการพิมพ์ หรือ จัดการร้าน → เครื่องพิมพ์ · ตรวจว่าอุปกรณ์ที่จับคู่เปิดหน้า POS/จอครัวอยู่ (งานพิมพ์ถูกส่งโดยอุปกรณ์นั้น) และ Print Agent ทำงาน
  • ไม่มีเสียง: แตะหน้าจอหนึ่งครั้งหลังเปิดหน้า เพื่อให้เบราว์เซอร์อนุญาตเสียง
  • จอลูกค้าไม่อัปเดต: ดูมุมล่างขวาของจอว่า "เชื่อมต่อแล้ว" · ถ้าถูกยกเลิกให้จับคู่ใหม่
